# تسيير المكتبة — مشروع Android قابل للتطوير

هذا المشروع يحتفظ بتطبيق الويب الأصلي داخل `www/` ويستخدم Capacitor لبناء تطبيق Android.

## بناء APK من الهاتف عبر GitHub Actions
1. ارفع محتويات هذا المشروع إلى مستودع GitHub جديد، مع الحفاظ على المجلد `www/` و`.github/workflows/`.
2. افتح تبويب **Actions** في المستودع وفعّل GitHub Actions إذا طُلب منك ذلك.
3. شغّل سير العمل **Build Android APK** من زر **Run workflow**، أو ادفع أي تعديل إلى فرع `main`.
4. بعد نجاح البناء، افتح نتيجة التشغيل ثم نزّل artifact باسم `maktaba-debug-apk` وفك ضغطه للحصول على `app-debug.apk`.

## التطوير لاحقاً
عدّل ملفات التطبيق داخل `www/`، ثم ارفع التعديلات إلى GitHub. يمكن فتح المستودع لاحقاً باستخدام Claude Code لمتابعة تطوير المصدر.

## ملاحظات
- ملف APK الناتج من هذا المسار هو نسخة Debug للتجربة والتثبيت، وليس إصداراً منشوراً على Google Play.
- اختبر النسخة على جهازك قبل الاعتماد عليها. قد تحتاج ميزات الكاميرا والماسح الضوئي والطباعة والبصمة إلى اختبار وضبط إضافي.
- احتفظ بنسخة احتياطية من بيانات التطبيق؛ البيانات المخزنة محلياً في المتصفح/التطبيق لا تنتقل تلقائياً بين الأجهزة أو الإصدارات.
